# QuickChat Part 3 Features

## Message Management
The application allows users to send, store and disregard messages.

## Arrays
The application maintains collections of sent, stored and disregarded messages, together with message IDs and hashes.

## Stored Messages
Users can display senders and recipients, find the longest stored message, search by message ID or recipient, delete a message by its hash, and generate a full message report.

## JSON Storage
Stored messages are saved using JSON and can be loaded for reporting and searching.
